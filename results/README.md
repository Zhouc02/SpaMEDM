This folder stores the results of SpaMEDM

## Description
The ```SpaMEDM_seed``` in obs is identification result, ```SpaMEDM_C_seed``` in obsm is the representation of SVD_U from ```post_proC``` function, and ```SpaMEDM_emb_seed``` in obsm is the representation of ```emb_norm```, which is used for UMAP visualization.
